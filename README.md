# 🔐 Cipher Lab

An open crypto-analysis workbench built with **React + TypeScript + Vite**.

<img src="public/cipher-lab.svg" alt="Cipher Lab icon" width="80" />

---

## What is this?

Cipher Lab is a browser-based toolset for exploring classical cryptography — think Enigma simulators, frequency analysers, and substitution cipher crackers.

## Tech stack

- **[Vite](https://vitejs.dev/)** — fast development server & bundler
- **[React 18](https://react.dev/)** — UI framework
- **[TypeScript](https://www.typescriptlang.org/)** — type-safe JavaScript
